# Built-in icon style

- Use a `24 × 24` viewBox and define `width` and `height` as `24`.
- Use `currentColor` so the UI controls icon color.
- Use a `1.6` stroke with round caps and joins for the outline style.
- Keep shapes simple and recognizable at the UI's 16–20 px sizes.
- Keep icons monochrome; use filled details only for small marks that improve recognition.
- Draw project-owned SVGs in this folder instead of mixing in another icon library.
